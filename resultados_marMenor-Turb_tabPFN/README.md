# 📁 resultados_marMenor-Turb_tabPFN

Output folder for the **Turbidity (Turb)** analysis pipeline.

This directory stores all figures, models, metrics, and serialized results generated by `usetFPN_v4-metrics-Turb.py`.

## Contents

### 📊 Exploratory Data Analysis (EDA)
| File | Description |
|------|-------------|
| `eda_mar_menor_turb.pdf` | 9-panel exploratory analysis |
| `distribution_negative_values_turb.pdf` | Histogram of negative sensor readings |
| `turbidity_value_analysis.pdf` | Full distribution + zoom near zero |
| `correction_comparison_turb_strategy_*.pdf` | Before/after negative-value correction |
| `categorization_comparison_mar_menor_turb.pdf` | Ecological vs. statistical categories |

### 🤖 Model Results
| File | Description |
|------|-------------|
| `model_comparison_mar_menor_turb.pdf` | Overall model comparison |
| `model_comparison_classification_mar_menor_turb.pdf` | Classification models only |
| `model_comparison_regression_mar_menor_turb.pdf` | Regression models only |
| `improvement_comparison_classification_turb.pdf` | Optimized classification models |
| `improvement_comparison_regression_turb.pdf` | Optimized regression models |

### 📈 Scientific Figures
| File | Description |
|------|-------------|
| `figure4_calibration_curves_turb.pdf` | Calibration curves (reliability diagrams) |
| `figure5_time_accuracy_tradeoff_turb.pdf` | Time–accuracy Pareto frontier |
| `figure6_radar_chart_turb.pdf` | Radar chart of top 5 models |
| `figure4c_temporal_decomposition_turb.pdf` | Temporal decomposition (seasonal/yearly) |
| `figure5_feature_importance_turb.pdf` | Feature importance (tree-based) |
| `figure5_feature_importance_tabpfn_turb.pdf` | Feature importance (TabPFN permutation) |
| `learning_curve_*_turb.pdf` | Individual learning curves per model |

### 📉 Regression Diagnostics
| File | Description |
|------|-------------|
| `regression_scatter_*.pdf` | Predicted vs. actual scatter plots |
| `residuals_plot_*.pdf` | Residual analysis plots |

### 🧮 Confusion Matrices & Metrics
| File | Description |
|------|-------------|
| `confusion_matrix_*_mar_menor_turb.pdf` | Confusion matrices per model |
| `perclass_metrics_*_mar_menor_turb.pdf` | Per-class accuracy/precision/recall/F1 |
| `computational_metrics_mar_menor_turb.pdf` | 6-panel computational metrics dashboard |
| `time_accuracy_tradeoff_mar_menor_turb.pdf` | Time–accuracy scatter plot |
| `smote_balancing_mar_menor_turb.pdf` | SMOTE class-balancing visualization |

### 💾 Serialized Data
| File | Description |
|------|-------------|
